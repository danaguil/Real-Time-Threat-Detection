# ThreatScope — Real-Time Threat Detection Dashboard

A full-stack cybersecurity dashboard that ingests simulated server logs, analyzes them for suspicious patterns, and visualizes threats in real time.

---

## Overview

ThreatScope simulates a Security Operations Center (SOC) dashboard. A log simulator generates realistic attack traffic (brute force, SQL injection, port scans, XSS), a Python backend parses and detects threat patterns in real time, and a React frontend visualizes alerts as they happen.

This project is **not** attacking any real system. The simulator generates fake log entries to feed the detection and visualization pipeline.
